expnote 中文文档
==================

expnote 用 SQLite 保存训练与实验记录和 benchmark 矩阵。用 CLI 写入记录，
用本地 Web UI 浏览与比较。Research 提供在研究 vault 中管理计划、证据和结论的流程。

* :doc:`tutorials/experiments` 从记录第一次训练开始，建立任务与算法对照矩阵。
* :doc:`tutorials/research` 用合成数据走完从提出问题到审阅结论的流程。
